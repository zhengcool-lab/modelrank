## B 组小结

- **P0 阻断：0**
- **P1 严重：1**（B-05 对比器移动端第二模型列不可见、数值被裁、横滑无提示且行名丢失）
- **P2 一般：5**（B-01 相关新闻兜底误导、B-02 折叠项 15px 触控、B-06 四模型列头截断、B-07 chips 26px 触控、B-08 成本页长列表无搜索）
- **P3 轻微：4**（B-03 站外标签竖排、B-04 价格重复且单位不一致、B-09 模型名截断、B-10 选择上下文不共享）
- 复现置信度：B-05 / B-06 / B-07 / B-08 / B-09 均有截图 + 诊断 JSON 或探针数值；B-01 / B-10 有截图 + 源码定位；B-02 / B-03 / B-04 为截图目视 + JSON 数值。
