- 评审对象：`https://modelrank-1br.pages.dev`（ModelRank 模型榜）
- 评审日期：2026-11-13
- 视角：投资人（商业价值与增长潜力）／AI 忠实用户（功能深度、效率、可信度）／刚接触 AI 的小白（门槛、术语、引导）
- 端：PC（1440×900 主档 + 1280×800 中档 + 320×700 极窄档）／移动端（390×844 主档，iOS 逻辑分辨率）；浅色为基准，关键页补深色

## 1. 总体结论

- 41 条问题：**P0 阻断 0 / P1 严重 3 / P2 一般 18 / P3 轻微 20**。
- 三端的整体完成度差异明显：**桌面端是「可用的半成品」，移动端在三个功能页上是「不可用的半成品」**——对比器的第二~四个模型列、Agent 详情的套餐价格表、成本页的模型选择器，都因固定宽度容器在 390 视口下失效。
- 最伤商业价值的两条不是布局，而是**叙事自相矛盾**：`/disclaimer` 仍写着「本站为示例/mockup 站点，部分数据为虚构」，而 `/about` 反复强调「不编造、不填充、可逐条核对」。投资人读完法务页会直接推翻整站可信度。
- 可信度资产本身是硬的（分数单一来源 AA、价格标官方来源与核对日、询价不算免费、S/A/B/C 为编辑评估非跑分），但这些资产**在移动端无法被使用、在内容层被「相关新闻」等兜底逻辑稀释**。

### 三个视角的结论

**投资人（商业价值与增长潜力）**
- 差异化成立：「搬运 + 可核对 + 不卖榜 + 拒做二次加权」这套口径在同赛道里是稀缺的，且已落到数据字段（`checkedAt`、官方 pricing 来源、询价档）而非口号。
- 但三个转化断点都在移动端：核心对比功能失效（P1-B-05）、价格决策页不可读（P1-C-07）、法务页否认数据真实性（P1-C-15）。任何一条被真实用户撞上，都是一次流失或一次可信度质询。
- 增长回路基本为零：无 OG 图卡（A1-5）、无对比结果分享、无订阅落地形态（B1-3 仅按钮）、内容策展偏热点搬运（C-02），自然传播与留存都缺钩子。

**AI 忠实用户（功能深度 / 效率 / 可信度）**
- 深度够用：52 模型 × 五维 × 价格 × 上下文 × 速率 × 成本计算器 × 28 个 Agent 三分类，信息密度在同类里属上游。
- 效率被三处打断：对比列头全是省略号（B-06）、成本页 52 个模型无搜索（B-08）、Agent 榜 28 条无排序筛选（C-06）。
- 可信度被两处反噬：「相关新闻」兜底取全站最新（B-01）、免责声明自称 mockup（C-15）。资深用户对这两类文字的敏感度最高。

**刚接触 AI 的小白（门槛 / 术语 / 引导）**
- 首页与模型库的引导是合格的（空搜索有热门词、能力档阈值直接印在筛选旁、价格缺失如实标注）。
- 术语墙集中在三处：五维（财务/战略/法律/工程/经济）无就近解释（A1-7）、Agent 的「倍率/编码·自动化·调研」只靠页尾说明（C-04）、数据来源的「污染风险」（C-12）。
- 移动端触控普遍偏小：26–32px chips、15px 折叠头、8×13 关闭钮，多页诊断 JSON 记录 8–57 个 <34px 目标，误触后无反馈。

## 3. 跨页面共性问题

### 3.1 移动端「横向内容」承载策略缺失（1 条 P1 + 4 条 P2，最高优先级族群）
三页同一病根：**固定宽度列 + `overflow:hidden`／`overflow:auto` 且无提示**。
- `/compare`：表格 680px 内容挤进 357px 容器，第二列不可见、数值被裁、横滑后行名丢失（P1-B-05）。
- `/agent/[id]`：价格表 420px 挤进 357px、`overflow:hidden` 直接裁掉备注列（P1-C-07）。
- `/cost`：52 个模型双列平铺，选择器占满首屏（P2-B-08）。
- `/library`：厂商 chips 2125px 内容藏进 329px 容器，无渐隐、无「共 N 家」（P2-A2-1）。
- `/agents`：tab 文案被迫两行（P3-C-05）。
**统一判定**：移动端需要一条「表格/长列表 → 卡片化或 sticky 首列 + 显式横滑指示」的布局规范，而不是逐页打补丁。

### 3.2 文案承诺与实现不闭环（可信度族群，1 条 P1 + 5 条 P2）
| 承诺位置 | 承诺内容 | 实际 | 后果 |
|---|---|---|---|
| `/disclaimer` | 本站为 mockup、部分数据虚构（P1） | 全站真实抓取、标核对日 | 直接否定整站可信度 |
| `/disclaimer` | 「页面底部邮箱」 | 页脚无邮箱 | 想纠错的人无门 |
| `/about` | 「免责声明与申诉页登记」「详情页底部留言」 | 两处皆不存在 | 同上 |
| `/methodology` | 「下方申诉入口」 | 移动端整块 `w=0` | 移动端无申诉 |
| `/data-sources` | 「详情页底部企业咨询留资」 | 无该组件 | 反馈/线索双失 |
| `/news` | 发布/评测/融资/政策/价格五类 | 实际只有发布、融资 | 分类承诺落空 |
**统一判定**：全站反馈入口应收敛为**一个真实可用的渠道**（表单或 mailto），并在四页同文案互指；法务页文案必须与产品事实同步。

### 3.3 触控目标系统性偏小（移动端一致性，8 页命中）
| 页面 | <34px 目标数 | 典型样本 |
|---|---|---|
| `/compare` | 30 | chips 26px 高、「✕」8×13 |
| `/cost` | 57 | 模型按钮 32px 高 |
| `/agent/[id]` | 36 | 「MasterGo 定价」358×18 |
| `/detail/[id]` | 12 | 折叠头 317×15 |
| `/news` | 11 | chips 28px 高 |
| `/data-sources` | 12 | 基准卡片内链 |
| `/about` | 9 | 05 节内链 |
| `/404` | 7 | 热门模型卡片 |
**统一判定**：建议按「主操作 ≥44px、次操作 ≥34px」立一条移动端基线，优先修 chips、折叠头、关闭钮三类高频控件。

### 3.4 术语墙与解释入口过远（小白门槛）
五维（财务/战略/法律/工程/经济）无解释（A1-7）、Agent「倍率/编码·自动化·调研」只靠列表页最底部说明（C-04）、「污染风险高/中/低」只有颜色（C-12）、成本页「缓存命中率/α」虽有默认提示但仍属专业词。
共同解法：**胶囊/表头 hover 一句白话解释 + 二级页方法论深链**，成本极低、收益覆盖全部专业术语。

### 3.5 兜底填充冒充精确内容（信任成本）
`/detail` 的「相关新闻」在无匹配时取全站最新（B-01），标题仍写「相关」。同类风险还存在于 `/compare` 的「高分推荐·点击加入对比」（推荐逻辑未标注为「按综合分」）与首页「查看完整榜单」按钮（A1-6）。**判定**：凡「相关/推荐/完整」字样，要么精确，要么标注口径并给空态。

### 3.6 元信息与分享能力缺失（SEO / 传播）
14 条路由全无 `canonical`、无 `og:image`（A1-5）；404 title 未区分（C-18）；`/agent` 无列表页（设计如此，但可重定向）。
共同解法：统一生成 canonical + 动态 OG 图（榜单 Top10 / 模型详情分数字卡），一次性解决分享与索引两个目标。

## 6. 方法与局限

- **取证方式**：`shot.py` 统一脚本（webkit 27.2/2370）逐页双端截图并输出 `failedRequests / consoleErrors / overflow / smallTargets / brokenImages`；关键缺陷另用自建探针读取 `clientWidth / scrollWidth / getBoundingClientRect` 与源码行号交叉验证。所有 40 条均有可复查的截图文件名或探针输出。
- **未覆盖**：本次未做真实的超大数据集搜索结果压测（A3 已标注建议补测）、未做网络弱化下的首屏表现、未做无障碍读屏脚本实测（仅按尺寸与对比度判断）。
- **明确剔除的旧说法**：「输入模态与 `multimodal=false` 矛盾」（当前数据未复现，证据不足，不写入）；「详情页三页同款相关新闻」（现为兜底取最新，已按实测改写为 B-01）；「成本页不消费对比预置」判定为设计选择而非缺陷，降级为发散方向 B-D11。
