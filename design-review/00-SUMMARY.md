## 三、全站共性问题（跨页面反复出现，建议一次性治理）

这 6 个主题在多个页面重复出现，应作为设计系统级别的一次性修复：

1. **辅助灰字 `--mr-text-3:#86909c` 对比度不达标**：在白底实测 3.24:1、在 `#f2f2f7` 底 2.9:1，全站首页表格、新闻摘要、Footer 链接、方法论帮助文案都在用。**建议**：浅色模式加深到 `#5b6470`（≥4.6:1），深色模式提亮。
2. **全站无 `:hover` / `:focus-visible` / `transition`**：应用 CSS 中三类规则数均为 0，鼠标划过表格行/卡片无反馈，键盘 Tab 无焦点框。**建议**：全局补 `:focus-visible{outline:2px solid var(--mr-primary);offset:2px}` + 表格行 hover 底色 + 150ms 过渡。
3. **圆角体系混乱（2/4/6/8px 四种并存）**：卡片 8px、按钮 4px、角标/徽章 2px、chip 6px。**建议**：token 化为 `--radius-sm:4 / --radius-md:6 / --radius-lg:8`。
4. **图标风格混用（emoji / Unicode / SVG / 位图）**：导航里"🔍 搜索""🌙 深色"用 emoji，汉堡菜单用 SVG，厂商 logo 用位图。**建议**：统一为线性 SVG 图标集，去掉 emoji。
5. **内联 `padding:24px 44px` / `44px 44px` 硬编码不响应式**：对比器、方法论、About/数据来源/免责声明三个内页都写死 44px，手机上左右吃掉 88px。**建议**：统一改用项目已有的 `.mr-pad-x`（移动 16px / 桌面 44px）。
6. **日期/时间格式三种写法并存**：首页"10-16 08:00"（月-日缺年）、详情页"2026-10-12"（ISO）、新闻"2 小时前"（写死字符串）。**建议**：统一相对时间 + tooltip 显示完整 ISO 日期。

## 四、完整问题清单（按页面分组）

### 【首页 / 榜单】(/ )

1. **[P1] 同一批 Top 25 模型在首页重复展示两遍**：先有完整排行表格（1–25 名），下方又来一套同样的大卡片榜单，两个"查看完整榜单"入口并存，信息架构冗余。建议：二选一，或把第二块改为"上升最快"等差异化定位。
2. **[P1] 全站基础字号偏小，维度小分仅 10px**：CSS 中 `font-size:10px` 出现 101 处、`12px` 出现 403 处、body 仅 13px。建议：维度小分提到 12px，正文最小 14px。
3. **[P1] 移动端标签随模型名长度错位**：375px 下 GPT-5 的"闭源+S档"与名字同行，Claude Opus 4.5 名字更长导致标签掉到第二行，不同卡片标签位置不齐。建议：标签固定排在模型名下方一行。
4. **[P1] "性价比"列用语与颜色语义模糊**：表格用"高/中/低"文字+底色，"低"档却是浅绿底（看似好评）；筛选器又用 S/A/B/C 字母档，两套体系并存。建议：统一为 S/A/B/C 色块。
5. **[P1] 涨/跌箭头颜色对比度不足**：上涨绿 `#2e9e5b` 实测 3.41:1、下跌红 `#d4481a` 4.43:1，均未过 AA 4.5:1。建议：绿加深到 `#1f7a44`、红加深到 `#c0392b`。
6. **[P1] Hero 主标题层级偏弱**：桌面主标题仅 24px/600，与 13px 正文差距小，缺视觉重心。建议：主标题提到 32–36px/700。
7. **[P1] 表格行无斑马纹、无 hover 整行高亮**：行分隔线 `#f2f3f5` 与页面背景同色，跨五列扫视易串行。建议：奇偶行交替浅灰底 + hover 品牌浅蓝底。
8. **[P2] 数字列未右对齐、未用等宽数字**：评分/价格列左对齐，小数点纵向参差。建议：`text-align:right` + `font-variant-numeric:tabular-nums`。

10. **[P2] 表格内 padding(24px) 与页面容器(44px) 不对齐**：表格里的"排名/模型"文字比上方标题内缩 20px。建议：统一左右基线。
11. **[P2] 排名奖牌色对比度不足**：银牌 `#c0c0c8` 在浅灰背景上几乎隐形，铜牌偏暗。建议：银牌加深为 `#8a919e` 或改带浅底奖牌徽章。
12. **[P2] 性价比 C 级徽章浅灰底配浅灰字，几乎读不出**。建议：S/A/B/C 四级用色相递进，每级对比度 ≥4.5:1。

40. **[P2] 首屏 SSR 只输出"加载中…"无骨架屏**：弱网下白屏感强。建议：做服务端骨架屏（空状态卡片+表单占位+横表骨架）。

### 【成本计算器】(/cost)

41. **[P1] 单位体系在"万"与"M/百万"之间无提示切换**：输入框写"4000（万）"，算式却用"40M"，用户需心算 ÷100。建议：统一对外单位为 M，或在结果区标注"= 40M tokens"。
42. **[P1] 模型选择分段按钮换行凌乱**：8 个按钮 flexWrap 后"Claude Sonnet 4.5"孤行第二行，右侧大片空白。建议：改为等宽 grid 或 flex:1 均分。
43. **[P1] 结果卡片固定 `width:400` 在手机上横向溢出**：375px 下可用宽 343px，卡片写死 400px。建议：去掉固定宽，移动端 `flex:1 1 100%`。
44. **[P1] 缓存命中率算式显示成小数 `(1−0.3)` 与按钮"30%"对不上**。建议：算式统一写成 `(1−30%)`。
45. **[P1] 同卡片内数字千分位不统一**：标题"¥1,884"带千分位，明细"≈¥1800"不带。建议：所有金额走同一格式化函数。
46. **[P1] 表单 label 未关联控件、range 滑块/按钮组缺 aria 语义**：裸 `<div>` 当 label，range 无 `aria-valuetext`，按钮组无 `role="radiogroup"`。建议：补全 label htmlFor 与 aria 属性。
47. **[P2] "同预算可考虑"名不副实且不可点击**：固定取列表第 2、3 个模型，与预算无关；渲染为纯文本 div 无链接。建议：按真实成本排序，做成可点链接。
48. **[P2] 月 token 输入框无单位后缀、无千分位、清空时静默归零**。建议：加后缀"万 tokens"，为空时结果区置灰"—"。
49. **[P2] 两个分段控制器视觉语言不一致**：模型组 flex 撑满，缓存组 inline-flex 靠左。建议：统一为同一种 segmented-control 样式。
50. **[P2] 结果数字切换瞬间跳变，无过渡**：金额从 ¥1,884 直接跳到 ¥2,355。建议：加 150–250ms 数字滚动或 opacity 过渡。
51. **[P2] 货币符号直接用 ¥，无币种说明**：海外模型以人民币标价无口径说明。建议：补"按 ¥/1M tokens 折算"或提供 USD/CNY 切换。

### 【方法论】(/methodology)

52. **[P0] 整页横向 padding 写死 44px 不响应式**（见全站共性 #5）。
53. **[P0] 右栏 `width:360 flex:none` 无 flexWrap，手机上两栏不堆叠**：左栏被压到接近 0 宽，正文溢出。建议：容器加 `flexWrap:wrap`，右栏移动端 `flex:1 1 100%`。
54. **[P1] "导出快照（占位）"占位文案直接外露**：未完成功能的开发文字出现在生产 UI。建议：隐藏按钮或改禁用态"即将上线"。
55. **[P1] "对结果有异议？申诉 →"是无 onClick 的死按钮**：点击毫无反应。建议：链到 `/disclaimer` 或 mailto，未做之前先隐藏。
56. **[P1] 数据源清单表格无表头，污染风险无视觉分级**：五行 flex 三列排布无列标题，"高/中/低"纯文字无 badge 着色。建议：加表头 + 污染风险 badge 红/黄/绿。
57. **[P1] 两套权重体系并列却无映射关系**：上方"维度权重"（推理 0.35/代码 0.25…）与下方"基准权重"（LMSYS 35%/GPQA 20%…）都是 100%，但没说哪个基准归入哪个维度。建议：在表格加"对应维度"列。
58. **[P2] 长文缺少章节锚点导航（TOC）**：多章节长文无 sticky 目录。建议：右栏做 sticky TOC + scroll-spy。
59. **[P2] 正文行宽过长无 max-width**：1440px 下一行排 60+ 汉字，超舒适行宽。建议：正文加 `max-width:65ch` 居中。
60. **[P2] 更新日志日期缺年份**：`10-16`、`10-12` 只有月日。建议：统一 `2026-10-16` 完整日期。
61. **[P2] 符号 α 在两页含义冲突**：成本计算器里 α=输入占比，方法论里 α=指数平滑系数。建议：两处改名区分（如方法论改用 β）。
62. **[P2] 辅助说明文字对比度低于 WCAG AA**（见全站共性 #1）。

66. **[P1] 摘要与元信息用 `#86909c` 对比度不达标**（见全站共性 #1）。
67. **[P1] 分类筛选按钮无键盘焦点样式**：全局 `outline` 未保留，Tab 用户看不到停在哪个分类。建议：补 `:focus-visible` 焦点环。
68. **[P2] 每张卡片重复挂"AI 摘要"灰标签**：6 张卡片无一例外，属无信息增量装饰。建议：删除卡片内 badge，改在副标题说明一次。
69. **[P2] 卡片双列 `maxWidth:434px` 写死**：宽屏右侧空 200px，末行单卡左对齐；平板区间被迫单列。建议：改 `repeat(auto-fill,minmax(340px,1fr))` 响应式网格。
70. **[P2] 空状态仅一行灰字，无插画、无"清除筛选"恢复路径**。建议：补轻量空状态（图标+"查看全部新闻→"）。

72. **[P2] 副标题与分类 tabs 文案完全重复；移动端 tabs 不换行有溢出风险**。建议：副标题改为价值说明一句，tabs 容器加 `overflow-x:auto`。

### 【搜索页】(/search)

73. **[P1] 搜索框常态就是蓝色边框+蓝色光晕，看起来永远聚焦；同时 `outline:none` 让键盘焦点不可见**。建议：常态用灰边框，`:focus` 时才加蓝边框+光晕。
74. **[P1] `autoFocus` 自动抢焦点，input 无 aria-label**：打开页面即被滚到输入框，读屏跳过面包屑。建议：去掉 autoFocus（或仅在 `?q=` 时保留），加 `aria-label="全站搜索"`。
75. **[P1] 搜索结果完全无关键词高亮**：输入"deepseek"后结果里相关字样无 `<mark>` 标记。建议：命中子串包 `<mark>` 高亮。
76. **[P1] 无实时建议下拉、无搜索历史/热门词、无一键清空按钮**。建议：输入时前缀补全下拉（↑↓ 可选）+ 最近搜索 chip + input 右侧清空 ×。
77. **[P1] 结果行固定列宽（160+160px）移动端溢出，长标题无 ellipsis**。建议：移动端改纵向堆叠，文本列补 `min-width:0`+ellipsis。
78. **[P1] 新闻结果只展示标题，不展示命中的摘要片段**：搜摘要里的词时用户误以为没搜到。建议：新闻结果改为标题+摘要命中片段两行结构。
79. **[P2] 零结果时两个分区各自提示，无统一空状态**：模型(0) 和新闻(0) 两条割裂灰卡片。建议：全空时显示统一空状态+推荐词 chips。
80. **[P2] 无分类 Tab 与结果总数汇总；两类结果跳转行为不一致**（模型跳站内/新闻跳站外）无视觉区分。建议：顶部加"共 N 条"，新闻行加"新窗口"小字。
81. **[P2] 导航"🔍 搜索"用 emoji 字符按钮**（见全站共性 #4）。
82. **[P2] 输入框触控高度仅 32px 偏小；"搜索"按钮在即时过滤下冗余；引导文案三处重复**。建议：输入框提到 40px+，三处引导只保留 placeholder 示例词。

### 【全局导航 / Footer / 组件】

83. **[P1] 激活导航链接未设 `aria-current`**：读屏用户无法识别当前页。建议：激活 `<Link>` 补 `aria-current="page"`。
84. **[P1] 汉堡菜单 aria-label 写死"打开菜单"，面板缺 Esc/点外部关闭、未锁 body 滚动**。建议：aria-label 随状态切换，监听 Esc 与路由变化收起。
85. **[P1] Footer 链接无下划线、颜色过浅，与"·"分隔符无法区分**：`#86909c` 12px 对比度 2.9:1。建议：链接加下划线或 hover 出现，颜色加深到 `--mr-text-2`。
86. **[P1] 全站无 `:focus-visible` 焦点样式**（见全站共性 #2）。
87. **[P2] Sticky 导航滚动后无阴影/毛玻璃**：白色导航与白色内容融为一体，位置感弱。建议：滚动 >8px 后加 `box-shadow` + `backdrop-filter:blur(8px)`。
88. **[P2] 搜索入口用 emoji「🔍」而非 SVG**（见全站共性 #4）。
89. **[P2] Logo 旁"模型榜"徽章圆角 2px 与全站不一致**（见全站共性 #3）。
90. **[P2] 共享 Footer 缺联系方式与社交链接，跨页面信息不一致；无"回到顶部"**：首页底部有邮箱/微信/GitHub，内页 Footer 只有 4 个文字链接。建议：把联系方式收进全局 Footer。
91. **[P2] 版权年份硬编码 © 2026，无备案信息**。建议：年份改 `new Date().getFullYear()` 动态输出，预留备案号位。
92. **[P2] 全站无返回顶部按钮**：首页 26 行表格+新闻长列表，滚到底后只能手动回滚。建议：scrollY>400 后右下角淡入"↑"按钮。
93. **[P2] 无独立 Toast 通知体系**：留资提交仅靠按钮变绿，失败无反馈。建议：封装全局 Toast 组件 + `aria-live="polite"`。

### 【关于 / 数据来源 / 免责声明】

94. **[P1] 内容区 padding 硬编码 44px**（见全站共性 #5），手机上正文仅剩 287px 宽。
95. **[P1] 长文容器 maxWidth 未居中**：1440px 下正文贴左、右侧 600px 空白。建议：加 `margin:0 auto`。
96. **[P1] "污染风险"徽章彩色底配灰字，无图例**：浅红底灰字，用户无法直觉判断"高"是危险还是好事。建议：文字同步加深（高 `#c0392b`/中 `#9a6a00`/低 `#2e7d4f`），加图例。
97. **[P1] 法律文案混入英文单词"respective"**："均为其 respective 权利人的商标"。建议：改为"各自"。
98. **[P2] 页面大标题用 `<div>` 而非 `<h1>`，整页无标题层级**：搜索引擎与读屏无法按标题导航。建议：页头改 `<h1>`，卡片标题改 `<h2>`。
99. **[P2] "我们承诺：不接受付费排名"核心信任声明无视觉强调**：淹没在三段灰文字里。建议：包左侧主色边条 + 浅蓝底 callout 块。
100. **[P2] 公开页暴露内部源码路径 `apps/web/src/lib/seed-data.ts`**。建议：改为"内部数据仓库统一维护"。
101. **[P2] 兄弟信息页内容宽度不统一（760 / 820）**。建议：统一为 720–760px。
102. **[P2] 免责声明页缺副标题，页头结构与兄弟页不一致**。建议：补一句"信息仅供参考，最终以厂商官方文档为准"。
103. **[P2] `metadataBase` 指向旧 workers.dev 域名**：分享卡片抓取会指向旧域名。建议：改为当前正式域名或环境变量。
