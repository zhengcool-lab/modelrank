关于 ModelRank

独立、透明、可申诉的大模型能力排行榜

ModelRank 是一个面向开发者与技术决策者的大模型能力排行榜。我们把公开可复现的基准测试结果按统一口径聚合加权，输出 0–100 的综合分，并同步展示价格、上下文、速率等采购相关指标，帮助你在选型时少踩坑。

我们承诺：不接受付费排名、不接受厂商充值上榜
任何模型的排名只由其在公开 benchmark 上的实测成绩决定，厂商无法通过付费影响分数或排序。我们也不接受"定向刷榜"——一旦发现训练数据污染，会在方法论页面披露污染风险并下调权重。

本榜数据全部来自公开 benchmark（LMSYS Chatbot Arena、GPQA、LiveBench、SWE-bench Verified、C-Eval 等，口径见 方法论）。页面中的价格为各厂商公开 API 报价，仅供参考，实际以官方为准。当前站点为示例/mockup 版本，数据用于演示榜单形态。
